# Roadmap

Each phase ends with something Jeymarc can see (a preview URL or a mockup) and his go before the
next one starts.

## Phase 0 — Setup (now)
- Git repo, docs, agents (Keystone, Shield), `apple-design` skill, `scripts/check.sh`.
- Astro + TypeScript + Tailwind scaffold that builds and passes checks.
- Shield pass on every outside service: Strava, Instagram, MapLibre/OpenFreeMap, Resend,
  Turnstile, Keystatic, Vercel Hobby (org repos, terms), Vercel Analytics, Lucide.
- **Jeymarc:** register jeymarc.com + jeymarcsison.com; create the GitHub repo; connect Vercel.

## Phase 1 — Design and landing page
- Mockup page for approval: palette (emerald/forest, light and dark), type, motion, icon style,
  placeholder portrait cut-out with scroll motion.
- Landing as a long scroll, one full chapter per section, each ending in a deep-dive link:
  hero + portrait, Now, About (LinkedIn link), Interests, Running, Travel, Projects, Blog, links
  hub, contact form. Section pages exist as simple stubs so the links work. Theme toggle.
  Privacy notice page.
- Deployed to a Vercel preview URL.

## Phase 2 — Blog and CMS (built 2026-11-08)
- Keystatic admin: posts, Now section, photo upload.
- Blog list and post pages, "Learning AI in public" series, RSS, share images.

## Phase 3 — Running (jeymarc.logs)
- Strava profile link, and official Strava embeds (click-to-load) for the runs Jeymarc picks.
- Run reports (races and special runs) with photos.
- Race results board, World Marathon Majors tracker.
- Instagram: hand-picked posts now, live feed once jeymarc.logs is a creator account.

## Phase 4 — Travel
- Themed MapLibre map (light/dark), a pin per trip.
- Trip pages: photo highlights, short story, link to the Polarsteps journey.

## Phase 5 — Projects
- City Run page; projects as a content collection so adding one is a new entry.

## Phase 6 — Launch
- Domain and redirects, SEO and share images, accessibility and performance pass, 404 page,
  real portrait, go live.
